Resolve eke use karana widiha
  1. Rec.709 footage: Color page eke node ekak hadala, right click → LUT → oyage .cube eka danna.
  2. S-Log3 direct: CST nathuwa, clip eke first node eke correction karala, LUT eka anith node ekata danna.
  3. CST → Rec.709 / Cineon Film Log: CST eke Tone Mapping eka None karanna. Input space eka "Cineon Film Log" thoranna.
  4. LUT folder: Project Settings → Color Management → Open LUT Folder. Ekata .cube eka copy karala Update Lists karanna.
  5. Strength: LUT node eke Key → Key Output Gain eka adu karala look eka adu karanna puluwan.
PowerGrade mode eka wada karana widiha
  1. Resolve eke oyage PowerGrade eka clip ekakata apply karanna.
  2. Viewer eke right click → Grab Still. Gallery eke still eka right click → Export → PNG / JPG.
  3. E still eka step 1 ta, ona tone eke photo eka step 2 ta danna.
  4. Hambena LUT eka PowerGrade eke last node eka widihata danna (node ekak add karala → LUT).
  5. Still eka right click → "Save as PowerGrade" / aluth still ekak grab karala PowerGrades album ekata danna. Ethakota PowerGrade eka target tone ekata change wela thiyenawa.

.drx file eke node values (lift / gamma / gain) kelinma edit karanna Resolve eken public format ekak denne na. E nisa me app eka PowerGrade eka match karana correction LUT ekak hadanawa.

Style match eken different photos dekaka "tone eka" match karanawa (brightness distribution, colour zones, hue wise saturation). 100% exact match ekak ona nam, same frame eka grade karapu version eka "Same frame" mode ekata danna.
